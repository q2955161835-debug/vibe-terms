# 跨模块验收：查词到项目学习

## 汇总表格

| 功能 | 场景 | 等级 | 验证方式 | 预期结果 |
| --- | --- | --- | --- | --- |
| 查词到理解 | 非首页搜索并阅读词条 | L2 | 真实 HTTP 浏览器流程 | 搜索命中词条，定义、边界、示例、来源可读 |
| 理解到练习 | 完成词条内小练 | L2 | 浏览器交互与 IndexedDB 读回 | 即时反馈正确，attempt 持久化 |
| 练习到路径 | 进入相关项目章节 | L2 | 普通链接导航 | 章节说明产物、检查点和关联词 |
| 恢复与携带 | 刷新、导出与重新导入 | L3 | 浏览器持久化流程 | 本地进度恢复，v2 导出可验证导入 |

## 详细报告

### 场景：从全局搜索完成一个项目学习闭环

1. 打开 `/{locale}/knowledge/`，用全局搜索输入一个规范名或本地标题。
2. 用键盘选择词条，确认本地标题、规范英文名、定义、边界、动态/静态示例和来源均可见。
3. 回答词条内练习并确认即时反馈；读取 `exerciseAttempts` 的对应稳定 ID。
4. 通过词条路径入口进入一个章节，核对章节产物、完成检查点与所有关联词链接。
5. 刷新页面确认记录仍在；导出 schema v2 JSON，验证结构后重新导入。
6. 在 390px 视口重复关键导航并确认无横向溢出、移动搜索关闭后焦点回到触发按钮。

预期：从查词、理解、练习到项目章节全部使用同一静态内容和本地状态；关闭账号、网络写入或 JavaScript 时，核心内容和普通链接仍可使用。
