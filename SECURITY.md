# Security Policy

The current prototype has no accounts, private API, or server-side user
storage. Guest learning progress is stored in the visitor's browser.

Once the public GitHub repository is available, report security vulnerabilities
through a private GitHub Security Advisory. Do not publish credentials, personal
learning exports, or exploit details in a public issue.

Include the affected route or file, reproduction steps, observed impact, and
browser or environment details. Ordinary content corrections and non-security UI
bugs may use normal issues.
