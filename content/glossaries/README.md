# Localization glossary

`terminology.yaml` is the editorial vocabulary sheet for the 500-term corpus.

- English is the canonical source language.
- Simplified/Traditional Chinese titles in this overlay are machine-assisted draft terminology.
- Japanese, Korean, German, Russian, and Hindi titles intentionally preserve the English canonical term until a human reviewer approves a localized display name.
- A locale file with `status: draft` must not be treated as publication-grade translation.
- Translators should update both the glossary and the matching `content/terms/<slug>/<locale>.yaml` file in the same pull request.
- Do not translate protocol, library, or product names merely to make every title look localized.
