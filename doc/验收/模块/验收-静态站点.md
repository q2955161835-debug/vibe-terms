# 静态站点模块验收

## 汇总表格

| 功能 | 场景 | 等级 | 验证方式 | 预期结果 |
| --- | --- | --- | --- | --- |
| 内容构建 | 八语垂直原型 | L2 | 运行公共站验证脚本 | 8 个语言、7 个分类、12 个术语全部生成且内容合同通过 |
| 响应式布局 | 390px 术语详情页 | L2 | 运行 Chromium 渲染测试 | 八种语言页面均无横向溢出 |

## 详细报告

### 内容构建

- 步骤：安装 `requirements-dev.txt`，执行 `scripts/verify_public_site.sh` 对应的 Python 内容、打包和 JavaScript 检查。
- 预期：内容结构、搜索索引、内部链接、SEO 结构和静态打包全部通过。

### 响应式布局

- 步骤：运行 `tests/test_render_harness.py::test_all_locales_render_home_and_term_pages_without_horizontal_overflow`。
- 预期：390px 视口下主页与术语详情页的 `scrollWidth` 不大于 `innerWidth`。

### 游客学习

- 步骤：运行 `tests/test_render_harness.py::test_guest_learning_uses_local_fallback_without_login`。
- 预期：无需登录即可创建学习队列，复习反馈产生下一次复习时间并保存在本地。

### Sites 适配

- 步骤：运行 `npm run build`、`npm run test:js`，再对本地 Sites 开发服务探测根页、语言页、术语页、样式资产和未知路径。
- 预期：`dist/server/index.js` 存在；有效路径和资产返回 200；未知路径返回 404。
