## 详细报告

### 内容构建

- 步骤：运行 `python scripts/audit_full_content.py` 与 `python -m pytest tests/test_content_schema.py tests/test_topic_taxonomy.py tests/test_project_paths.py tests/test_full_corpus.py -q`。
- 预期：唯一 slug/名称、版本、关系、42 主题唯一覆盖、三路径章节引用与 4000 个语言文件全部有效；draft 不冒充人工审校。

### 全局搜索与知识地图

- 步骤：运行 `npm run test:js`、静态路由测试和真实 HTTP 搜索流程；分别在桌面与移动端从非首页调用搜索。
- 预期：精确词首位、主题和路径分组存在；方向键、Enter、Escape、`Ctrl/Cmd+K`、移动对话框关闭后的焦点返回全部正常；普通链接在无 JS 时仍可访问。

### 富词条、示例与练习

- 步骤：检查代表词条初始 HTML 的 definition/prerequisites/example/exercise/agent-prompt/sources 段；操作一个注册动态示例与单词小练。
- 预期：内容无需 JS 即可阅读；增强交互不执行内容脚本或第三方 iframe；练习以稳定 option id 判题并保存结果。

### 本地数据

- 步骤：在浏览器中写入旧 v1 记录并加载新版，完成练习后刷新；验证 `vibe-terms-local-v2` 的 `termProgress`、`exerciseAttempts`、`pathProgress`、`bookmarks`、`recentViews`；测试有效导入、无效导入和确认清空。
- 预期：迁移幂等且不丢记录；无效导入不改变现有数据；清空只删除 Vibe Terms 本地数据；全程无登录或网络账户依赖。

### 部署

- 步骤：分别以空 `BASE_PATH` 与 `/vibe-terms` 构建，运行 `npm run build`；通过 GitHub Actions 发布后读取 workflow、Pages deployment 和线上路由。
- 预期：accepted commit 与远端 `main` 一致；GitHub Pages 根、`zh-cn`、词条、知识地图、路径章节、练习和静态资源返回 200，canonical/资源 URL 带正确前缀。
